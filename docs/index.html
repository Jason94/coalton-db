(WITH-TRANSACTION OP) FUNCTION · src

∀ :M :A. Monad :M ⇒ FreeT DbF :M (Result DbError :A) → FreeT DbF :M (Result DbError :A)

Execute the given database operation inside of a transaction. If the operation returns an Err value, rollback the transaction and bubble the error. Otherwise, commit the transaction and return the Ok value of OP. If an intermediate query fails but the entire transaction returns an Ok value, it will commit!
